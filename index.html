数理図譜 投稿ツール

このページは、YouTube チャンネル「数理図譜 / SURI ZUFU」（@surizufu）の運営者が、自分のチャンネルへ動画を投稿・予約するために使う個人用ツール（suri-zufu-publish）の説明ページです。

このツールは YouTube Data API を使って、運営者自身のチャンネルに対してだけ次の操作を行います。

  • 動画のアップロード（初回は必ず非公開）
  • 公開予約の設定と、処理状況・公開状態の確認
  • サムネイルの設定（運営者が承認した場合のみ）

一般の利用者向けのサービスではなく、第三者のアカウントやチャンネルにはアクセスしません。
