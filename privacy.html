プライバシーポリシー

制定日: 2026年10月21日

「数理図譜 投稿ツール」（以下「本ツール」）は、YouTube チャンネル「数理図譜 / SURI ZUFU」の運営者が自分のチャンネルを管理するために使う個人用ツールです。本ツールは YouTube API サービスを利用しています。

1. 取得する情報

本ツールは、運営者本人が Google アカウントで許可した範囲で、次の情報にアクセスします。

  • 運営者のチャンネルの ID と名前
  • 運営者がアップロードした動画の情報（タイトル、公開状態、予約日時、処理状況）

運営者以外の利用者の情報は取得しません。

2. 利用目的

取得した情報は、運営者のチャンネルへの動画の投稿、公開予約、投稿結果の確認にだけ使います。広告、分析目的の販売、その他の目的には使いません。

3. 保存と管理

認証情報（アクセストークン）は運営者の PC 上にだけ、Windows の暗号化機能（DPAPI）で暗号化して保存します。外部のサーバーには送信・保存しません。

4. 第三者への提供

取得した情報を第三者に提供、販売、共有することはありません。本ツールによる Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. アクセス権の取り消し

本ツールへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。また、Google のセキュリティ設定からも取り消せます。

6. 関連する規約

本ツールの利用には YouTube 利用規約 が適用されます。Google による情報の取り扱いは Google プライバシー ポリシー をご覧ください。

7. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネル @surizufu の概要ページからご連絡ください。

8. 改定

本ポリシーを改定する場合は、このページで改定日とともにお知らせします。
